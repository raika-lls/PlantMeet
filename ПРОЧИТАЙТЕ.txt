PLANTMEET : локальный учебный проект

ЗАПУСК
Дважды нажмите «Запустить PlantMeet.cmd». Требуется Node.js 24 или новее
(на этом компьютере уже установлен). Интернет и установка пакетов не нужны.
Адрес: http://localhost:4173
Оставляйте окно сервера открытым. Для остановки нажмите Ctrl+C в этом окне.
Если браузер открылся раньше сервера, обновите страницу.

КАК ПОКАЗАТЬ ПРОЕКТ
1. Откройте карту сайта. После «Онлайн-регистрация на дисциплины» нажмите
   «PlantMeet». Откроется отдельная вкладка.
2. На главной или в расписании нажмите «Присоединиться».
3. Разрешите камеру и микрофон. Если разрешение отклонено, можно продолжить
   без видео и включить устройства позже через настройки браузера.
4. За 18 секунд постепенно появятся 8 демонстрационных студентов.
5. Откройте чат, отправьте сообщение, поднимите руку, включите экран.
6. Нажмите «Запись» при включённой камере или демонстрации экрана.
   Нажмите повторно для сохранения. Записываются выбранное видео и
   доступные аудиодорожки, а не вся сетка с демонстрационными участниками.
   Для более надёжной записи не меняйте источник до её остановки.
7. Нажмите «Выйти». Журнал покажет время входа, выхода и длительность.
   Трем студентам, которые не вошли, будет выставлено «н.я.».
8. В «Записях» можно посмотреть и скачать настоящее записанное видео.

ВОЗМОЖНОСТИ
Главная, расписание с фильтрами, создание встреч, конференция, камера,
микрофон, демонстрация экрана, чат, поднятие руки, видеозаписи, журнал,
выгрузка CSV для Excel, настройки демонстрационных студентов.
Поля и сообщения проверяются и в браузере, и на сервере.

ДАННЫЕ
data/plantmeet.sqlite : база SQLite: встречи, профиль, посещения, чат,
метаданные записей. data/recordings : видео WebM.
Запись хранится один календарный месяц с момента сохранения.
Очистка выполняется каждую минуту, при просмотре списка и запуске сервера.
Если компьютер выключен, просроченные файлы удалятся при следующем запуске.
Чтобы перенести проект, скопируйте всю папку после остановки сервера.
Лимит одной записи : примерно 230 МБ, затем она сохраняется автоматически.
Перед обновлением страницы остановите запись: браузер не гарантирует
сохранение видео при аварийном закрытии. Если вкладка пропала, незавершённую
встречу можно закрыть кнопкой в журнале.

ГРАНИЦЫ УЧЕБНОГО ПРОЕКТА
Это самостоятельный локальный проект по визуальному образцу Platonus,
не подключённый к настоящей университетской системе. Ссылки внешних
разделов Platonus : элементы воспроизведённой карты сайта.
Русский интерфейс; KZ / RU / EN в шапке воспроизводят образец.
Без страницы входа, как запрошено. Данные относятся к одному локальному
профилю. Вымышленные студенты : имитация для демонстрации, их видео и
голоса не генерируются. Камера, микрофон и запись пользователя настоящие.
Сервер доступен только на этом компьютере. Для реальной многопользовательской
видеосвязи нужны WebRTC-сигнализация/SFU, TURN, HTTPS и авторизация.
Нельзя просто опубликовать эту локальную версию как защищённый сервис.

СТРУКТУРА
public/index.html : разметка входной страницы
public/style.css : оформление и адаптация под экран
public/app.js : страницы, конференция и клиентская логика
public/reference.png : предоставленный образец; логотип показан из него
server.mjs : локальный HTTP-сервер, API и SQLite
tests.mjs : проверки хранения, валидации и посещаемости (npm test)
package.json : описание проекта и команды запуска

В отчёте №3 перечислен вход, но он намеренно исключён по вашему запросу.
Основные компоненты и обработка ошибок реализованы по отчёту.

ОБНОВЛЕНИЕ

В расписании пять указанных предметов с лекциями по 50 минут и практиками
