# PlantMeet Cloud

Сетевая версия PlantMeet с общей базой и ролями.

Сайт: https://plantmeet-raika.aware-lynx-4498.chatgpt.site

## Пользователям

1. Каждый участник регистрируется по email и паролю (минимум 10 символов).
2. При регистрации указывает имя и выбирает роль: преподаватель или студент.
3. Первый преподаватель получает три начальные встречи. Он может создавать новые.
4. Студенты видят общее расписание с автоматическим обновлением каждые 5 секунд.
5. Преподаватель первым открывает встречу и входит в Jitsi, если сервис просит.
6. Студенты нажимают «Присоединиться» у той же встречи.

Роль сохраняется за аккаунтом. В учебной версии выбор роли самостоятельный,
без проверки трудоустройства. Студент не может повысить роль через повторную
регистрацию. Для проверки ролей нужны два разных аккаунта.

## Конференции

Видеосвязь, микрофон, камера, участники и чат работают через Jitsi Meet.
Сервис meet.jit.si требует от инициатора комнаты отдельного входа.
PlantMeet не назначает роли модератора внутри стороннего Jitsi.
Создание и завершение встреч в PlantMeet проверяются сервером.

Посещаемость отмечается после события подключения к видеокомнате.
Неявки выставляются зарегистрированным студентам после завершения встречи.
При потере связи последнее время активности остаётся в журнале.

Запись вкладки доступна в поддерживаемом браузере на компьютере. Для звука
выберите вкладку и разрешите передачу её аудио. Микрофон самого записывающего
может не входить в аудиопоток вкладки. Запись автоматически останавливается
около 20 МБ, сервер принимает до 25 МБ. Записи хранятся календарный месяц,
очищаются при обращениях к расписанию, удалить запись может её автор.

## Разработка

Node.js 24+, npm install, npm run dev. npm run build собирает Worker.
node --test tests.mjs проверяет серверную логику с разными идентичностями.
Данные хранятся в D1, видео в R2. Секретов и пользовательских данных в Git нет.
Схема находится в db/schema.ts, миграции в drizzle/.
Авторизацию обеспечивает Sites. Локальная имитация входа включается только
в режиме разработки; её нет в опубликованной сборке.

Исходники на GitHub не являются сервером. GitHub Pages может служить
страницей перехода в опубликованное приложение. Обновление файлов в GitHub
само по себе не публикует новую серверную версию Sites.

## Авторизация PlantMeet

Пароли хешируются PBKDF2-SHA256 со случайной солью (100 000 итераций). Сессии хранятся в общей базе, токены в базе хешируются. Cookie HttpOnly, Secure на HTTPS, SameSite=Lax; срок сессии 7 дней. Выход отзывает сессию. Запросы изменения проверяются на тот же Origin. Ограничение попыток входа действует по IP и email.

Почтовая отправка не настроена: email используется как логин, подтверждения email и сброса пароля нет. Старые платформенные аккаунты не привязываются автоматически по имени, чтобы не передать чужие занятия другому человеку. Старые записи и встречи сохраняются.
