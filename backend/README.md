# Общая база PlantMeet для Cloudflare

Этот сервер подготовлен, но еще не опубликован. На GitHub Pages общая синхронизация пока НЕ включена.

## Развертывание после входа в Cloudflare

Из папки backend:

1. `npx wrangler login`
2. `npx wrangler d1 create plantmeet`
3. Скопировать возвращенный database_id в wrangler.json вместо SET_AFTER_D1_CREATE.
4. `npx wrangler d1 migrations apply plantmeet --remote`
5. `npx wrangler deploy`
6. Подключить возвращенный HTTPS адрес API к интерфейсу GitHub Pages, заменить локальные операции создания/редактирования/удаления запросами API и включить обновление расписания каждые 5 секунд. До этого шага интерфейс остается локальным.

## Контракт

POST /session: name, role, group, subgroup. Возвращает серверный токен и идентичность.
GET /me: идентичность текущей сессии.
GET /meetings: общее расписание; студент видит свою группу и свою подгруппу либо встречи всей группы.
POST /meetings: title, date, time, kind, group, subgroup. Только преподаватель.
PUT /meetings/:id: изменение или closed=true, только автор.
DELETE /meetings/:id: только автор.

Авторизация: Authorization: Bearer <token>. В базе хранится SHA-256 хеш токена. URL видеокомнаты определяется сервером и одинаков для всех участников встречи. CORS разрешен для https://raika-lls.github.io. DEV_ORIGIN используется только при локальной проверке.

Это демоверсия: роль выбирается самостоятельно, без проверки статуса преподавателя. Не использовать реальные персональные данные. Для защищенного учебного сервиса нужно ввести подтверждение преподавателей и полноценные учетные записи. Старый демо-пароль интерфейса не является серверной авторизацией.

Тесты: Node.js 24+, `node --test tests.mjs`. Используется реальная SQLite в памяти с адаптером D1. Проверены независимые сессии преподавателя и студента, общая встреча, ограничения записи, проверка ввода и фильтрация подгрупп. Проверка удаленного Cloudflare и звонка с двух устройств выполняется после публикации.
