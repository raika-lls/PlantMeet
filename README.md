# SmartEdu

[Қолданбаны ашу](https://raika-lls.github.io/PlantMeet/)

SmartEdu — желілік бағдарламалау пәнінің қазақша оқу кеңістігі. Кітапханада 15 дәріс пен 18 зертханалық жұмыс жинақталған.

**Оқытушы** материал жүктейді, тапсырма немесе тест дайындайды, ЖИ ұсынған балды қарап, түзетіп бекітеді. **Студент** кітапханадан оқиды, дереккөздері көрсетілген жауап алады және тапсырма тапсырады.

**Конференция** бөлімінде PlantMeet-тегі Jitsi бейнебөлмесі қолданылады. Сервер қосылу аралығын тіркейді, ал ЖИ студенттің сабақ сұрағына берген жауабын бағалайды. Қатысуға 6, жауапқа 4 балға дейін беріледі. Оқытушы қорытындыны өзгерте алады.

## Бірге көрсету

1. Оқытушы сайтта рөлін таңдап, топ кодын сақтайды. Өз кабинетіне кіру үшін аты мен құпиясөзін пайдаланады.
2. Студент басқа браузерден немесе құрылғыдан дәл сол топ кодын енгізеді. Әр студент өз атын және құпиясөзін қолданады.
3. Оқытушы тапсырманы жариялайды. Студент жауап бергеннен кейін жұмыс «Бағалау» бөлімінде көрінеді.
4. Оқытушы конференцияны ашып, бөлмеге бірінші кіреді. Jitsi жүргізушіден өз сервисінде кіруді сұрауы мүмкін. Сабақ аяқталғанда әр студенттің қатысу есебі жасалады.

ЖИ қолдану пайызы студенттің өз мәлімдемесінен алынады. Жазбаша жұмысқа берілген автоматты ұсынымды оқытушы бекітеді.

## Іске қосу

- Интернеттегі нұсқа осы репозиторийдің GitHub Pages беті арқылы ашылады. Интерфейс пен API бір Cloudflare Worker-де. Пән деректері D1 базасында, жауап генерациясы Workers AI арқылы орындалады.
- Windows-та жергілікті демоны SmartEdu.cmd файлы іске қосады. Python 3.10+ және PDF жүктеу үшін pypdf қажет. Бұл нұсқада бір оқытушы және бір студент кабинеті бар. Жергілікті модель конфигурациясы SmartEdu/model ішінде көрсетілген.
- Интерфейс және бастапқы материалдар SmartEdu/web ішінде. Бұлттағы сервер backend/smartedu.mjs, D1 схемасы backend/migrations/0007_smartedu.sql ішінде.
