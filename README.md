# PlantMeet

Локальный учебный проект по визуальному образцу Platonus.

## Запуск

Требуется Node.js 24 или новее. Дополнительных зависимостей нет.

Дважды нажмите `Запустить PlantMeet.cmd` или выполните `npm start`.
Откройте http://localhost:4173.

## Функции

* Расписание пяти предметов. Лекция: 50 минут, практика: 90 минут.
* Конференция с камерой, микрофоном, демонстрацией экрана и чатом.
* Восемь демонстрационных студентов с постепенным подключением.
* Журнал посещаемости, неявки и экспорт CSV.
* Запись камеры или экрана, просмотр, скачивание и удаление видеозаписей.
* Автоматическое удаление записей через календарный месяц.
* Имя пользователя: Арайлым. Страницы профиля и входа нет.

## Данные

SQLite создаётся автоматически в `data/plantmeet.sqlite`, видео хранятся в
`data/recordings`. Эта папка исключена из Git, чтобы личные видеозаписи и
история занятий не публиковались. Для переноса всех данных скопируйте папку
проекта целиком после остановки сервера. Удаление видео не удаляет журнал.

Очистка просроченных записей выполняется при запуске сервера и во время его
работы. На выключенном компьютере очистка произойдёт при следующем запуске.

## Проверки

`npm test` проверяет посещаемость, сохранение после перезапуска, миграцию
имени и расписания, длительность, удаление видео и срок хранения.

## Ограничения

Сервер работает только на этом компьютере. Демо-студенты не являются
реальными удалёнными участниками. Камера, микрофон и запись пользователя
настоящие. Для видеосвязи между компьютерами необходимы дополнительные
сервисы WebRTC, TURN/SFU, HTTPS и авторизация. Проект не подключён к
настоящему университетскому Platonus.
